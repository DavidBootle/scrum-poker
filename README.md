# Bootle's Scrum Poker

A simple scrum poker utility.

## Running
1. Clone the repo to your local machine. Make sure that docker is installed.
2. Run `npm install` in both the `backend/` and `frontend/` directories.
3. In the repo root, run `docker-compose up --build`. This will start the relevant services.

## Access
- Redis: `localhost:6379`
- Frontend: `localhost:4173`
- Backend: `localhost:3000`
